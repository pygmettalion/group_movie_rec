# Korean-comment copy (for teammates) / 한국어 주석본 (팀원용)

This folder holds the **same source code** as the repository root, with the original **Korean** comments and docstrings.
The code in the repository root (English comments) is the official, runnable version; the executable code is identical
(verified: the Python ASTs match exactly once docstrings are ignored).

이 폴더는 저장소 루트와 **똑같은 코드**에 **한국어 주석**을 단 읽기용 사본이다.
실행과 제출 기준은 루트(영어 주석) 코드이며, 실행 코드는 한 글자도 다르지 않다.
루트에서 실행해야 경로(data/, results/)가 맞으므로, 이 폴더의 파일은 읽기용으로만 쓴다.
