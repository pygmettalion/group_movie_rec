# Demo page: "4플릭스" (4-flix)

A wordplay name: "넷" means four in Korean, so the first syllable of a famous streaming name is swapped for the number 4 — "a movie service for the four of us".
A one-page demo of the frozen v1 model for the presentation.

## Open it
Double-click `frontend/index.html`. It works in any browser without a server or Python.
(With an internet connection the Pretendard font is loaded from a CDN; offline, system fonts are used.)

## What it shows (for one of the 49 official MovieLens groups, or one of 200 random groups of 4 users)
- **Hero:** the Top-1 recommendation of the Risk-Aware model, the average predicted rating of the 4 members, and the probability that someone strongly dislikes it.
- **Top 5 row:** the five candidates with the highest Final Score; the plain Average method's pick is marked when it differs.
- **Seats and members:** the 4 members in a seat map (colour = how each member is predicted to feel), each member's predicted rating, and their own Strong Dislike threshold (bottom 5% of their past ratings).
- **Ticket and comparison:** a booking-style summary, and what the Average method would have picked and why the model avoided it (6 of 49 groups).

Posters are original pixel-art scenes generated per movie for this project (`scenes.js`: one recipe per genre — sky, landscape, props — varied by a seeded random generator; small characters in `sprites.js`). No real movie posters are used.
The seat map is decorative.

## Where the numbers come from
`frontend/data.js` is generated by `frontend/build_data.py` from the frozen model (`results_v1_frozen/`), with the same procedure as `05_demo.py`, for the 49 official groups and 200 random groups of 4 users (any users with ≥ 10 past ratings, fixed seed)
(candidates = movies none of the 4 has rated, same reliability filter, Final Score = mean − 0.75 × risk). Nothing in the model is changed.
To regenerate (needs `data/` and, for titles, `data_extra/ml-1m/movies.dat`):
```bash
python frontend/build_data.py
```
